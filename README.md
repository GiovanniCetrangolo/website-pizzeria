# Pizzeria Sasà

A responsive website for a fictional pizzeria, developed using HTML5, CSS3 and Bootstrap 5.

The website includes a homepage with an image carousel, a pizza menu, a special offers page and a modal form for simulating orders.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive layout for desktop and mobile devices
- Navigation bar built with Bootstrap
- Image carousel on the homepage
- Pizza menu with product cards and prices
- Special offers section
- Modal window with a demonstration order form
- Custom CSS styling and hover effects

## Pages

- **Home:** introduction to the pizzeria and featured content
- **Menu:** pizza selection and prices
- **Offers:** special pizzas and promotional prices

## Notes

This project was created for learning and portfolio purposes. It is a frontend-only demonstration: the order form does not submit or store orders, and the business information is fictional.
